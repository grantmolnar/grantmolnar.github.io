# Adventure Reference-Library Completion Record

## Purpose

This document records completion of the reference-library program across the bundled adventure corpus. The feature uses persistent references for stable people, organizations, places, and objects while leaving changing route, custody, pressure, resource, and relationship state in the adventure or play journal.

## Completed sequence

Every bundled adventure completed:

1. primary-person and authority extraction;
2. supporting-subject extraction and omission review;
3. post-extraction prose and heading repair; and
4. whole-adventure coherence review.

The current reference libraries, ordered encounter links, generated reference sheets, and runtime views are the maintained result. The per-adventure extraction logs and closing audit files were historical work products and have been removed.

## Compatibility boundary

Reference IDs, kinds, link order, adventure schema fields, journal history, archives, imports, and exports remain compatibility-bearing. A future cleanup must not rename or regenerate those identities merely to improve presentation.

Changing situational facts remain outside persistent references. Examples include current custody, roster membership, route availability, pressure, injury, resources, permissions, and consequences established during play.
